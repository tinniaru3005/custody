# HTTP API

Every route below is served both at its own path and under `/api` (the console uses `/api/...`). Paths are tenant-scoped: `{tenant}` is a slug matching `[a-z0-9][a-z0-9_-]{0,62}` and selects the graph `<prefix>:<tenant>`. Request and response bodies are JSON.

FastAPI's interactive reference with full schemas is at `/swagger` (also `/redoc` and `/openapi.json`) on any deployment that is not in public-demo mode. Route code: [`custody/api/routes/`](repo:custody/api/routes/); request models: [`custody/api/schemas.py`](repo:custody/api/schemas.py).

> [!WARNING]
> The API has no authentication. Anyone who can reach it can record data, approve actions and run scenarios for any tenant. Outside [public-demo mode](/docs/deployment#public-demo-mode), put it behind your own authentication proxy.

## Meta

| Method | Path      | Returns                                                                                                                    |
| ------ | --------- | -------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/health` | `{"status": "ok" \| "degraded", "falkordb": bool, "version", "public_demo": bool}`, plus `demo_tenant` in public-demo mode |

## Recorder

All writes return `201 Created` with the stored record. The `record/*` bodies (except `record/approval`) accept optional `session_id`, `metadata` (object) and `id` (a client-supplied id); `record/approval` accepts `id` only. Writes validate referenced ids first and return 404 for a missing one without writing the Datum or Action (the agent's `system:agent:<agent>` Source may already have been created).

| Method | Path                                                               | Body                                                                                                                                                             | Notes                                                                                                                                |
| ------ | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| POST   | `/tenants/{tenant}/sources`                                        | `id`, `kind`, `trust`, `metadata?`                                                                                                                               | Register a Source explicitly. `kind`: `user`, `web`, `vault`, `email`, `github`, `slack`, `system`. `trust`: `trusted`, `untrusted`. |
| POST   | `/tenants/{tenant}/record/user-input`                              | `text`, `user`, `agent?`, `sensitivity?`                                                                                                                         | Source `user:<user>`, trusted.                                                                                                       |
| POST   | `/tenants/{tenant}/record/web-content`                             | `content`, `url`, `agent?`                                                                                                                                       | Source `web:<url>`, untrusted.                                                                                                       |
| POST   | `/tenants/{tenant}/record/external-content`                        | `content`, `kind`, `ref`, `trust?` (default `untrusted`), `sensitivity?`, `agent?`                                                                               | Email, GitHub, Slack and similar. Source `<kind>:<ref>`.                                                                             |
| POST   | `/tenants/{tenant}/record/vault-secret`                            | `secret`, `path`, `agent?`                                                                                                                                       | Source `vault:<path>`, trusted; stored with `sensitivity: secret`, value masked.                                                     |
| POST   | `/tenants/{tenant}/record/llm-output`                              | `text`, `agent`, **`derived_from`** (every Datum id in the context window), `model?`, `sensitivity?`, `coverage?`                                                | `coverage`: `FULL_CONTEXT` (default) or `REDUCED`. Sensitivity defaults to the highest of the parents.                               |
| POST   | `/tenants/{tenant}/record/memory`                                  | `content`, `agent`, `derived_from` (at least one), `key?`, `sensitivity?`, `coverage?`                                                                           | A shared memory (`Datum:Memory`).                                                                                                    |
| POST   | `/tenants/{tenant}/record/memory-recall`                           | `memory_id`, `agent`, `query?`                                                                                                                                   | `409` if the memory is quarantined.                                                                                                  |
| POST   | `/tenants/{tenant}/record/message`                                 | `content`, `sender`, `recipient`, `derived_from`, `thread_id?`, `sensitivity?`, `coverage?`                                                                      | An inter-agent message.                                                                                                              |
| POST   | `/tenants/{tenant}/record/action`                                  | `action_type`, `agent`, `destination` (Datum ids), `payload` (Datum ids), `extra_args?` (role → Datum ids), `sink?` `{destination, kind?, external?}`, `status?` | Records an Action with `ARG` and `TO` edges. Does not run the Guard.                                                                 |
| POST   | `/tenants/{tenant}/record/approval`                                | `approver`, `endorses` (Datum ids), `reason?`, `action_id?`                                                                                                      | Low-level endorsement record. Prefer the Guard's approve and endorse endpoints, which apply the guardrails.                          |
| PATCH  | `/tenants/{tenant}/actions/{action_id}/status`                     | `status`                                                                                                                                                         | `proposed`, `pending_approval`, `approved`, `blocked`, `rejected`, `executed`, `failed`.                                             |
| GET    | `/tenants/{tenant}/data/{datum_id}`                                |                                                                                                                                                                  | One Datum.                                                                                                                           |
| GET    | `/tenants/{tenant}/data/{datum_id}/lineage?max_depth=`             |                                                                                                                                                                  | Every ancestor Datum with its minimum depth and Source. `max_depth` 1–100.                                                           |
| GET    | `/tenants/{tenant}/data/{datum_id}/path-to/{target_id}?max_depth=` |                                                                                                                                                                  | A provenance path between two nodes. `404` only after a complete search found none; `503` if the search was incomplete.              |
| GET    | `/tenants/{tenant}/actions/{action_id}`                            |                                                                                                                                                                  | One Action with its arguments and sink.                                                                                              |
| GET    | `/tenants/{tenant}/actions/{action_id}/trace?max_depth=`           |                                                                                                                                                                  | The lineage of each argument plus the sink.                                                                                          |

## Guard

| Method | Path                                                              | Body                                          | Returns                                                                                                                                                                                                                                                                       |
| ------ | ----------------------------------------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST   | `/tenants/{tenant}/guard/actions/{action_id}/check?enforce=false` |                                               | `GuardDecision`. Always writes a `Decision` audit node; `enforce=true` also updates the action's status.                                                                                                                                                                      |
| POST   | `/tenants/{tenant}/guard/actions/{action_id}/approve`             | `approver`, `reason?`                         | Applies the approval the decision offers, re-checks, returns the new `GuardDecision`. `403` for a BLOCK (lethal trifecta or precedent), a hold with no approval option (incomplete search), an action already blocked, rejected, executed or failed, or a non-human approver. |
| POST   | `/tenants/{tenant}/guard/actions/{action_id}/reject`              | `approver`, `reason?`                         | Records `REJECTS`, marks the action `rejected`, returns the Action. An action already in a terminal status is returned unchanged.                                                                                                                                             |
| POST   | `/tenants/{tenant}/guard/endorse`                                 | `approver`, `datum_ids`, `reason?`, `egress?` | `201`, the Approval. `403` if a Datum feeds a blocked action. `egress: true` also pre-approves secret egress to the value the Datum holds.                                                                                                                                    |
| POST   | `/tenants/{tenant}/guard/sources/{source_id}/revoke`              | `approver`, `reason?`                         | `201`, a re-adjudication report: the Source becomes untrusted and every downstream historical action is re-checked.                                                                                                                                                           |
| GET    | `/tenants/{tenant}/guard/readjudications?limit=10`                |                                               | Recent re-adjudication reports (`limit` 1–50).                                                                                                                                                                                                                                |
| GET    | `/tenants/{tenant}/guard/actions/{action_id}/decisions`           |                                               | The action's audit trail of Decisions.                                                                                                                                                                                                                                        |

The fields of `GuardDecision` are described in [Guard → Decision shape](/docs/guard#decision-shape).

## Errors

Errors are JSON with a `detail` field.

| Status | When                                                                                                                              |
| ------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 400    | Invalid tenant slug; Warden `anthropic` planner without the SDK                                                                   |
| 403    | Approval refused (lethal trifecta, non-human approver, endorsing data that feeds a blocked action); any write in public-demo mode |
| 404    | Unknown Datum, Action or Source; another tenant in public-demo mode; no provenance path after a complete search                   |
| 409    | Recalling a quarantined memory                                                                                                    |
| 422    | Request validation failed, or an invalid value (for example an unknown enum)                                                      |
| 429    | Public-demo reset called again within `CUSTODY_DEMO_RESET_MIN_INTERVAL_S`; the response has `Retry-After`                         |
| 503    | `path-to` search incomplete, so Custody cannot say whether a path exists                                                          |

## Public-demo restrictions

With `CUSTODY_PUBLIC_DEMO=true` only `GET`, `HEAD` and `OPTIONS` requests to the demo tenant are allowed, plus `POST /tenants/{demo}/console/demo/reset`. Every other write returns `403`, any other tenant returns `404`, and `/swagger`, `/redoc` and `/openapi.json` return `404`. See [Deployment](/docs/deployment#public-demo-mode).
